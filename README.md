## 📌 About The Project

**AI Resume Analyzer** is a resume analysis and recommendation system designed to help students and job seekers understand and improve their resumes.

The application parses information from an uploaded resume and provides useful insights such as:

- 📄 Resume information
- 🛠️ Skills and keywords
- 💼 Predicted job role
- 📊 Resume score
- 🎯 Skill recommendations
- 📚 Course recommendations
- 💡 Resume improvement tips
- 🎥 Interview and resume-related resources

The project also includes an **Admin Dashboard** for viewing applicant data, feedback, and analytics.

---

## 🎯 Objectives

The main objectives of this project are:

- Automate the resume analysis process.
- Extract important information from resumes.
- Identify skills and keywords.
- Predict suitable job roles.
- Recommend skills and courses.
- Help users improve their resumes.
- Provide useful analytics to administrators.
